# Riesgos, Declaración de Aplicabilidad y control de calidad

**Responsable:** Amílcar Quispe Santos

## Por qué este rol

Los otros dominios encuentran problemas; este rol los **ordena por importancia** y verifica que todo esté sustentado. La matriz de riesgos (ISO/IEC 27005) decide qué se recomienda primero, y la Declaración de Aplicabilidad (SoA) muestra el estado de los 93 controles del Anexo A. También eres el revisor de calidad: ningún hallazgo pasa al informe sin evidencia.

## Tareas

| Tarea | Detalle |
|---|---|
| Matriz de riesgos | Activo → amenaza → vulnerabilidad → probabilidad × impacto → nivel → tratamiento. Usar el formato del examen del curso (`EJEMPLO Matriz de riesgos-complementado.xlsx`) |
| SoA | Los 93 controles de ISO/IEC 27001:2022 Anexo A: aplica / no aplica, justificación, estado actual, dominio que lo evaluó |
| Madurez | Consolidar el nivel 0–5 de cada dominio (D1–D5) en una tabla y un gráfico para el informe |
| Control de calidad | Revisar que cada papel de trabajo tenga procedimiento, evidencia y conclusión; que cada hallazgo apunte a un papel de trabajo |
| Índice | Mantener el índice de papeles de trabajo y evidencias |
